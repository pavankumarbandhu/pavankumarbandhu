# 🔵 TROUBLESHOOTING METHOD

| Step | Engineering Activity |
|---|---|
| **1. Identify** | Understand the failure and expected behavior |
| **2. Reproduce** | Recreate the issue consistently |
| **3. Collect** | Gather logs, traces and test results |
| **4. Isolate** | Narrow the failure to the affected layer |
| **5. Analyze** | Investigate hardware, firmware, driver, OS and network |
| **6. Resolve** | Apply corrective action |
| **7. Validate** | Confirm the fix and perform regression |
| **8. Document** | Record findings and defect details |
